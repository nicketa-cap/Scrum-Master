# Scrum-Master

## Test Prompts
- Analyze the current sprint data and identify leave conflicts, capacity gaps, and dependency risks. Provide recommendations to improve sprint planning.
- Are there any overlapping leaves in the team that could impact the sprint?
- Is any team member overloaded or underutilized in this sprint?
- Are there any tasks that depend on a single individual without backup?
- What actions should the Scrum Master take to improve sprint planning?
- Given the team’s leave schedule, capacity, and task dependencies, analyze risks for the upcoming sprint and suggest improvements for better resource planning.
